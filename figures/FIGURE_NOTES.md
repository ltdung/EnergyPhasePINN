# Revised manuscript diagrams

Both figures use the corrected revision model and the answered reviewer responses. SVG text, equations, connectors and drawings remain editable. Matching PDFs contain vector graphics and embedded fonts; PNGs are exported at 600 dpi. Both figures are 183 mm wide.

## Architecture caption

**EnergyPhasePINN architecture for nanoindentation loading.** (a) Grain size, temperature and indentation velocity are standardized using training data and encoded into 12 constrained parameters. (b) Analytical elastic, plastic and hardening energies are combined through depth-dependent sigmoid gates and supplemented by a learned residual energy. The same depth variable enters every depth-dependent computation, including derived depth features. (c) Predicted force is the full derivative of the scalar loading potential at fixed context, including branch, gate and residual derivatives. Force-data fitting, physics penalties and residual-weight regularization train the mean model. A separate heteroscedastic network is then fitted to residuals with the mean model frozen. The prime denotes differentiation with respect to indentation depth.

## Graphical abstract caption

**Energy-based learning of nanoindentation in AlCuNiTiZr.** Time-ordered MD loading data condition a gated elastic–plastic–hardening energy model; force follows by full differentiation of its scalar loading potential. The right panel shows the saved EnergyPhasePINN prediction and all 557 MD loading observations for held-out condition 0, seed 0. Depth is normalized by the maximum loading depth for that condition. The lower strip summarizes leave-one-condition-out evaluation across 18 conditions and five seeds: R² = 0.957 ± 0.040 (mean ± sample SD across 90 runs), with mean MAE = 7.07 nN. Each fold contains 14 training, three validation and one test condition. The atomistic drawing is schematic.

## Scientific scope and provenance

- The potential describes the modeled **loading branch**. Energy–force consistency is exact by construction; monotonic force, force positivity, Hertzian agreement and gate timing/separation are training penalties. The diagram does not assert complete thermodynamic admissibility or describe unloading.
- The gates are learned deformation-regime weights, not measured crystallographic phase fractions. The parameter transform orders nominal thresholds δh > δy; widths and biases also affect actual gate midpoints.
- In the architecture, **x is standardized context**, d = max(δ, 10⁻⁶), and softplus uses β = 10. Hidden activations are SiLU. The residual network also receives x, as written in its input label. The positive width floor is 10⁻³. These numerical conventions follow `revision_models.py`.
- The second-stage loss is Gaussian residual NLL plus 5 × 10⁻⁴ mean(σ), with σ = softplus₁₀(raw) + 10⁻⁴. The architecture shows the uncertainty mechanism, without asserting nominal coverage. See `revision_run.py`.
- Main metrics were verified from `results/runs.jsonl`, selecting `exp == "E3"` and `model == "EnergyPhasePINN"` (90 records). These revised results replace the submission's earlier single-split values. The figures make no claim of higher accuracy than PhasePINN.
- The example curve uses `results/figure_data/fig1_loading_branch.npz`: `y_true_new` and `y_pred_new`, generated by `generate_figure_data.py` with corrected loading extraction, LOCO fold 0, seed 0 and an 800-epoch maximum. Observations were checked against `Indent_AlCuNiTiZr.csv`, using `revision_data.keep_loading` and `revision_data.group_id`. All predictions are shown without smoothing. The curve is an illustrative saved run; the lower-strip statistics summarize the main 90-run experiment.
- Numerical depth and velocity ranges are omitted because their units are inconsistent across the supplied manuscript materials. The plot uses dimensionless normalized depth; force retains the reported nN units.

## Editing and export

Edit `architecture.svg` or `graphical_abstract.svg` directly in Inkscape or another vector editor, then export both with:

```powershell
python figures/make_diagrams.py
```

Inkscape must be installed; use `--inkscape /path/to/inkscape` if it is not detected. On this workstation, the working Python executable is `C:/Users/dungl/anaconda3/python.exe`.

The original redesigned layouts can be rebuilt using:

```powershell
python figures/build_architecture.py
python figures/build_graphical_abstract.py
python figures/make_diagrams.py
```

The graphical-abstract builder requires NumPy, pandas and the source data files above. Rebuilding overwrites manual SVG edits; exporting does not. Neither builder retrains or modifies the scientific model.
